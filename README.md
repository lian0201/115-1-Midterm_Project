# 那些建構劉竣銓的碎片們｜我的大學生活指南

> **資工系可以比想像中有趣——寫程式只是基本，真正厲害的人，都是一邊玩得很瘋，也一邊讀得很兇。**

這是一個以「大學生活與非典型資工系日常」為主題的個人互動網站，採用純原生 **HTML5、CSS3 與 Vanilla JavaScript** 開發，無使用任何外部前端框架或模板。

## 一、 專案簡介（Project Introduction）

- **網站目的**：透過網頁呈現大學生活的真實切片，分享如何在資工系繁重的課業、服務性社團與日常休閒之間取得平衡，並整理個人私藏的台北咖啡廳、宵夜與放鬆景點指南。
- **目標受眾**：
   1. 剛升上大學、正在摸索如何安排課業與社團時間的大一新生。
   2. 對資工系學生日常感到好奇，想認識程式以外多元面向的訪客。
   3. 尋找讀書咖啡廳、深夜美食或傍晚散步去處的學生族群。
- **主題發想**：大眾對資工系常有「整天對著螢幕寫程式、生活單調」的刻板印象。我希望藉由這個網站打破框架，記錄自己在 **國立臺北科技大學資訊工程系** 的學習日常，以及參與 **慈幼社**、**雀兒輕音社** 和平時拍照探店的生活樣態。

## 二、 網站架構與頁面功能（Website Structure）

全站共有四個相互連結的 HTML 頁面，並透過頂部固定樣式的全域導覽列（`<nav>`）與 `active` 高光提示，讓使用者能在各頁面間自由切換：

1. **`index.html`（首頁導覽）**
   - **滿版 Hero 視覺**：搭配漸層深色遮罩（`.overlay`）與左對齊標語，建立網站第一印象。
   - **個人簡介區塊**：透過 Flexbox 排版與圓形頭像裁切，介紹作者背景與建站初衷。
   - **2×2 生活核心網格（`.grid-2x2`）**：展示「社團參與、日常生活樣態、我眼中的閃光、怎麼讀大學」四大面向，滑鼠懸停（Hover）時標題會平滑滑動至左上角並浮現深色說明蒙版。
2. **`clubs.html`（學校生活）**
   - **社團經歷與時間管理**：使用無序清單（`<ul>`）介紹「慈幼社（562/563 營隊活動長）」與「雀兒輕音社（公演演出）」經歷，並以有序清單（`<ol>`）條列三項兼顧課業與社團的時間管理原則。
   - **115-1 學期課表（`.timetable`）**：運用 HTML `<table>` 結合 `rowspan` 與 `colspan` 合併連續節次與午休時間，並以獨立圓角卡片樣式呈現各科時段。
3. **`lifestyle.html`（日常生活小撇步）**
   - **JS 互動功能一「生活靈感切換器」**：提供「找安靜咖啡廳」、「學校附近私藏好店」、「單純休息跟放鬆」三顆按鈕，點擊後動態切換推薦地點（月里つきさと、深夜未歸、大稻埕碼頭）的照片、心得與外部連結。
   - **日常隨身清單**：列出通勤與讀書必備的隨身物品。
4. **`social.html`（你真的認識我嗎）**
   - **生活樣態三欄卡片（`.vibe-grid`）**：呈現攝影紀錄、探店與音樂散步三種日常狀態。
   - **JS 互動功能二「日常生活照放大燈箱」**：以 2×2 網格展示四張生活紀錄照，滑鼠移入顯示故事預覽，點擊照片可開啟滿版彈跳燈箱（Lightbox）檢視大圖與完整故事。
   - **社群媒體連結（`.social-grid`）**：提供 Instagram（`@lian.fln__v7`）與 GitHub（`@lian0201`）外部連結卡片。

## 三、 技術實作重點（HTML / CSS / JS）

### 1. HTML 結構設計

- **跨頁導覽列（`<nav>`）**：四個頁面皆共用一致的導覽結構，並透過 `class="active"` 標示使用者目前所在分頁。
- **結構化課表（`<table>`、`rowspan`、`colspan`）**：在 `clubs.html` 中使用 `rowspan="2"`、`rowspan="3"` 整合兩節或三節連堂課程（如資料結構、電子學實習），並用 `colspan="5"` 呈現跨五天的午休橫條。
- **多層次清單與圖片無障礙屬性（`<ul>`、`<ol>`、`<img>`）**：區分無先後順序的社團/隨身物品清單與有步驟邏輯的時間管理方法；全站圖片皆設定具描述性的 `alt` 替代文字。

### 2. CSS 版面與視覺設計（`style.css`）

- **全站一致性配色**：以溫暖米白（`#FAF8F5` / `#FDF8F2`）作為基底，搭配深森綠（`#1E3D37`）、陶土橘（`#E07A5F`）與暖金色（`#F2CC8F`），營造溫暖且具質感的閱讀體驗。
- **CSS Grid 響應式網格**：運用 `display: grid` 與 `grid-template-columns` 製作 2×2 與三欄卡片，並搭配 `@media (max-width: 768px)` 媒體查詢，在手機螢幕上自動轉為單欄排列。
- **定位與互動轉場（`position`、`transition`）**：利用 `position: relative` 與 `position: absolute` 製作照片懸停遮罩與燈箱右上角半透明關閉鈕；使用 `position: fixed` 讓燈箱視窗覆蓋全螢幕，並搭配 `transition` 讓按鈕與卡片產生平滑的懸停回饋。

### 3. JavaScript 互動功能（`script.js`）

- **功能一：`showGuide(category)`（動態內容與連結切換）**
   - **運作原理**：使用者點擊按鈕時傳入對應字串參數（`'cafe'`、`'food'` 或 `'relax'`），函式透過 `document.getElementById()` 取得標題、內文、圖片與連結元素，依條件判斷更新 `.textContent`、圖片 `.src` 與外部網址 `.href`，並透過 `.style.display` 控制區塊顯示或隱藏（例如景點類別自動隱藏 IG 按鈕）。
- **功能二：`openLightbox(card)` & `closeLightbox(event)`（DOM 節點讀取與燈箱控制）**
   - **運作原理**：點擊相簿卡片時透過 `this` 將該卡片元素傳入函式，利用 `card.querySelector()` 自動抓取內部的圖片路徑與標題說明，寫入燈箱視窗後將顯示狀態切換為 `display: flex`；點擊深色背景或右上角關閉鈕時，透過 `event.target` 判斷點擊來源並將燈箱重新隱藏。
